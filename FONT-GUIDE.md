# Fonts and readable classroom text

Use one heading font and one body font throughout the deck. The atmosphere comes from the artwork and palette, not decorative lettering.

| Role | Font | Starting size |
| --- | --- | ---: |
| Deck title | Georgia Bold | 52 pt |
| Slide heading | Georgia Bold | 38 pt |
| Body and instructions | Arial | 26 pt |
| Quotations | Arial | 28-32 pt |
| Brief labels and attribution | Arial / Arial Bold | 22 pt |
| Compact table or diagram labels | Arial | 20-22 pt when readable |
| Nonessential credits only | Arial | 16-18 pt |

Aim for 24 pt or larger for the material students must read. Keep body text left aligned, in normal capitalization, with roughly 1.15-1.3 line spacing. No cursive, handwriting, calligraphy or condensed display fonts. Use bold for emphasis; retain italics when they have a semantic role, such as a work's title.

## Font setup

Font binaries are not included. Check for Georgia and Arial in your presentation editor and in the environment generating the slides. Keep the same fonts available on the presenting computer. The complete sample lesson, teaching-layout library and motion pilot use Georgia and Arial.

If a font is unavailable, first use your organization's normal font-installation method. Otherwise choose one installed readable serif for headings and one installed sans serif for body text. Use that pair consistently across the deck, tell the teacher what changed, and check every slide again. A substitute font can change line breaks and text fit.

For Chinese text, use Microsoft YaHei when available for Chinese glyphs while retaining Georgia/Arial for English. If unavailable, select a readable installed Chinese font consistently and verify the actual glyphs. Do not assume a font exists on every operating system.

## Give text room

- Use warm ivory `#F2E8D5` on dark umber `#211B16` and deep umber on pale paper. Check contrast over the actual image.
- Keep text away from candles, shelves, borders, folds and transparent margins. Use the [spacious background guide](artifact-template-ae-humanities-ppts/references/spacious-backgrounds.md) for per-image text areas.
- Treat example word counts as starting points. Long words, bullets, extra headings or larger type use more room. Recheck fit after replacing sample text.
- Prefer the [quiet paper surfaces](artifact-template-ae-humanities-ppts/references/quiet-surfaces.md) for substantial reading. Split longer passages at meaningful boundaries.
- Keep text editable. Save a PPTX, then inspect the exact file that will be presented. Check both the authoring view and slideshow view; a projector can reveal problems that a laptop does not.

For the palette, spacing and composition rules, see the [design system](artifact-template-ae-humanities-ppts/references/design-system.md).
