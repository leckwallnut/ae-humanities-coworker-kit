# AE Humanities — Dark Academia Set 2

Ten PNG assets created with the built-in image generation tool. Transparent backgrounds allow layering over existing slide designs. Numbers continue from the first set.

11–13: horizontal dividers in torn paper, antique brass and burgundy velvet.
14: wax-seal heading label.
15: portrait quotation paper.
16: framed landscape text card.
17: dark slate text panel.
18: two-column comparison panel (one PNG).
19: arched parchment panel.
20: layered index card.

PowerPoint: Insert > Pictures, select a PNG, then add an editable text box above it. Use dark brown text on ivory panels and ivory text on slate or burgundy. Keep text inside the clean central area. Resize proportionally; crop excess transparent margins if useful. Group your text box and image to move them together.
