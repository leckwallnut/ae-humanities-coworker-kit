# Example decks

- [First-run test - Observation and Interpretation](<First-run test - Observation and Interpretation.pptx>) and its [animated version](<First-run test - Observation and Interpretation (animated).pptx>) are the reference result for the first-run test. See [what a good first-run result looks like](../artifact-template-ae-humanities-ppts/references/first-run-check.md).
- [Quiet Words: scary stories with Hemingway](<Quiet Words - Scary Stories with Hemingway.pptx>) is a complete 11-slide teaching example: notice a prose technique, compare a revision, infer from details, plan, write and revise. Its 100-150-word story task is an example, not a rule for other lessons. Source information and teaching notes are inside the deck.
- [Twenty editable teaching layouts](../artifact-template-ae-humanities-ppts/assets/teaching-layouts.pptx) is the main copy-and-adapt library. [The layout index](../artifact-template-ae-humanities-ppts/references/layout-library.md) identifies each slide's purpose and sample text load.
- [Four-slide motion pilot](../artifact-template-ae-humanities-ppts/assets/motion-pilot.pptx) demonstrates fades and click reveals. Read [the test limits](../artifact-template-ae-humanities-ppts/references/motion-pilot-guide.md) before adapting it.

All artwork in these PPTX files is embedded. Save your own copy before editing. The complete example and layout library use Georgia and Arial; see the [font guide](../FONT-GUIDE.md).
