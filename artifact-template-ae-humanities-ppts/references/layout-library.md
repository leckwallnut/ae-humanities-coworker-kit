# Editable teaching layout library

Copy examples from [teaching-layouts.pptx](../assets/teaching-layouts.pptx). This is a 20-slide widescreen PowerPoint in the saved Humanities style, with two versions of each teaching type. The numbers below are library slide numbers; renumber the finished lesson normally.

## Copy and adapt

Copy the entire selected slide and choose **Keep Source Formatting** in PowerPoint. Text, tables and timeline objects are editable, and the artwork is embedded. The source deck uses Georgia Bold headings and Arial body text.

Each slide has removable objects named template-label and template-capacity-guide, plus adaptation guidance in its speaker notes. Remove these guide objects before class. The demonstrated text load is a starting point, not an automatic maximum: long words, line breaks and replacement images change the fit. Keep text readable and recheck the edited slide.

All sample passages, quotations, biographical profiles and project scenarios are original teaching examples. Replace them with the teacher's material. Fictional biography and timeline examples are labelled. Generic generated statues are illustrations, not portraits of real people.
