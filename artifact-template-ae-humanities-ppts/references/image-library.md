# Bundled Humanities image library

The original 53 PNGs were made in **AE Humanities ppts**, on 1–2 October 2026 (Asia/Shanghai). They are AI-generated artwork. An earlier Unit 1 dark academia deck served as the first design reference. It is not included in the shared kit because it contains third-party images.

Paths below are relative to `assets/humanities-images/`. Images with transparency are the original PNGs, unchanged. Opaque images (full backgrounds and scenes) are high-quality JPEG copies with the same names and dimensions; the original PNGs are kept in the coworker kit's `Extras/Original images` folder, and each catalog entry records the original's checksum as `originalPngSha256`. The `README-prompts.md` records describe the original generation, so they still use the original `.png` names. Each set retains its original `README-prompts.md` with generation prompts and usage notes. [asset-catalog.json](asset-catalog.json) records exact paths, dimensions, transparency, visible alpha bounds, byte sizes, and SHA-256 hashes. Read selected metadata as needed rather than loading the full catalog for every deck.

## Placement and provenance

Alpha bounds describe the visible outer artwork, not a guaranteed safe text rectangle. Inspect each paper interior at full size. Crop surplus transparent margin only when needed, retaining the complete ornament or paper edge. Never flatten editable text into the image or stretch the image.

For notes, a concise provenance entry is sufficient: “Artwork: AI-generated asset from the user's AE Humanities ppts collection, [exact filename].” Do not present the pictures as photographs documenting a real historical event. Use authentic source images when the lesson needs visual evidence.
