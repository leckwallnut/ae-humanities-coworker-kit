# Starter prompts

Copy a prompt, replace the bracketed fields and attach the actual lesson material. These are starting points; adjust level, timing and slide count. If you are using the kit folder directly instead of an installed skill, replace the first sentence with: `Read ./artifact-template-ae-humanities-ppts/SKILL.md and use that skill for this task.` Plain wording works in every assistant; some also offer a shortcut, such as `/skill:artifact-template-ae-humanities-ppts` in Kimi Code or `$artifact-template-ae-humanities-ppts` in Codex.

## First-run test

Run this once after installing to check that the skill, its images and the host's PowerPoint tools all work. Compare the result with [first-run-check.md](references/first-run-check.md).

```text
Use the AE Humanities PPTs skill (artifact-template-ae-humanities-ppts) for this task. Confirm you can find the 20-slide layout library and the 117-image collection.

Create a three-slide, 16:9 editable PowerPoint introducing the difference between observation and interpretation. Use this original example: "The chair is empty. A wet coat hangs beside the door." Label it as a classroom example.

Slide 1: explain observation and interpretation. Slide 2: show the example with two discussion questions; keep suggested answers in notes. Slide 3: give a short independent practice task. Use Georgia Bold headings, Arial body text, and three different suitable layouts. Reuse the bundled images. Render and check the slides, and save the result in a new lesson-output folder. If presentation creation is unavailable, say so clearly and give the slide plan.
```

## 1. A brief explanation

```text
Use the AE Humanities PPTs skill (artifact-template-ae-humanities-ppts). Create a 5-slide editable 16:9 lesson explaining [concept] to [student level] in about 10 minutes. Use the attached source material. Include a clear definition, one concrete example, a useful comparison, a short check for understanding, and a closing task. Put suggested answers and sources in speaker notes. Use Georgia Bold headings, Arial body text, varied layouts and bundled images. Render and check readability before delivering the PPTX.
```

## 2. Close reading

```text
Use the AE Humanities PPTs skill (artifact-template-ae-humanities-ppts). Build a 6-slide, 20-minute close-reading lesson for [student level] from the attached passage. Preserve the exact quoted wording and source attribution. Begin with observation, then guide students to language choices, inference and a supported interpretation. Use quiet paper for the passage, one annotation layout and a brief independent response. Keep questions visible and suggested answers in notes. Keep all teaching text editable and check the exported PPTX for fit and contrast.
```

## 3. A discussion lesson

```text
Use the AE Humanities PPTs skill (artifact-template-ae-humanities-ppts). Create an 8-slide, 25-minute discussion lesson on [question] for [student level]. Use the attached material as evidence. Give a brief context, two defensible viewpoints, useful discussion language, clear group roles, time to consider a counterargument, and an individual exit response. Use the discussion preset but adapt its pacing. Distinguish sourced claims from invented teaching examples. Use varied comparison, debate and synthesis layouts, with large readable text and speaker notes.
```

## 4. A writing workshop

```text
Use the AE Humanities PPTs skill (artifact-template-ae-humanities-ppts). Create an 8-slide writing workshop for [student level] on [writing task]. The final writing should be [length] and the class lasts [minutes]. Use the attached assignment requirements. Include one clearly labelled original model, a worked revision, a planning step, writing time, success criteria and a simple peer-feedback task. Use clear actions and concrete details in the examples. Adapt the writing-workshop preset to the material. Keep constraints accurate, text editable and fonts readable. Deliver a checked PPTX with teaching notes.
```

## 5. Restyle an existing lesson

```text
Use the AE Humanities PPTs skill (artifact-template-ae-humanities-ppts) to restyle the attached deck in the Humanities style. Preserve its lesson sequence, required content, exercise answers and the following homework/source images: [identify them by slide or description]. Optional decorative images may be replaced with bundled artwork. Convert to 16:9, use Georgia Bold headings and Arial body text, and vary layouts by teaching purpose. Do not remove required material to make it fit; split crowded slides where useful and explain material changes. Render and inspect every finished slide before delivering an editable PPTX.
```

## 6. Add restrained motion after the static deck is ready

```text
Use the AE Humanities PPTs skill (artifact-template-ae-humanities-ppts) and its motion-pilot guide on the attached finished deck. Add subtle manual Fade transitions and click-to-reveal [answers / annotations / revision examples] on slides [numbers]. Keep passages, questions and essential instructions visible from the start. Work on a copy, finish any static export first, and on Windows with desktop PowerPoint add and confirm the effects with the skill's PowerPoint checks. State exactly what was tested and what remains unverified. If native effects cannot be preserved, deliver the static PPTX with a clearly labelled reveal plan in notes.
```

## A useful follow-up

```text
Check this deck for small text, busy backgrounds behind passages, repeated layouts and lost required content. Fix the problems while preserving editable text. Tell me which slides changed and how the final file was checked.
```
